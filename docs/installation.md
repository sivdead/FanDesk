# 安装与使用

## 首次安装

从 [FanDesk Releases](https://github.com/sivdead/FanDesk/releases/tag/v0.2.4) 下载 **`FanDesk-0.2.4-macos-arm64-notarized.dmg`**，打开后把 FanDesk 拖到 Applications 文件夹。从 `/Applications/FanDesk.app` 启动，避免直接在磁盘映像中运行。

当前包适用于 Apple Silicon 双风扇机型；已验证 Apple M5 Pro（Mac17,8），其他机型尚未实测。

### macOS 首次打开确认

文件名带 `-notarized` 的官方安装包已使用 Developer ID 正式签名并通过 Apple 公证。应用和磁盘映像均附带公证凭证，供 macOS 离线检查；首次打开时按系统的正常来源确认提示操作。

历史 0.2.2 Release 保留原始 `FanDesk-0.2.2-macos-arm64.dmg` 和对应的 `SHA256SUMS.txt`，它们采用 ad-hoc 本地签名、未经过公证。建议使用最新的公证安装包。

如需校验下载完整性，将公证安装包与 Release 的 **`SHA256SUMS-notarized.txt`** 放在同一目录，运行：

```sh
shasum -a 256 -c SHA256SUMS-notarized.txt
```

### 后台服务授权

打开 FanDesk 后点击“启用风扇控制”。按照系统提示前往“通用 → 登录项与扩展”，允许 FanDesk 在后台运行；不同系统版本的页面名称可能略有不同。管理员认证由 macOS 完成。

风扇写入需要特权后台服务；温度和 RPM 读取不需要这一权限。界面与后台通过 XPC 通信并相互校验代码签名，只有当前活动控制台用户的应用可以发出控制请求。后台不绑定打包者的账户编号。

授权后确认应用显示后台服务已连接，再应用设置。不要同时运行其他风扇控制器。

## 日常使用

两个风扇可以使用不同模式和温度来源。固定转速须在硬件允许范围内；温控曲线的起始温度和全速温度须相隔至少 5°C。曲线决定稳态目标：在起始温度以下为最低转速，区间内线性变化。从 0.2.2 起，温控会平滑日常温度变化，并缓慢降速；检测到原始选中温度达到全速温度或 CPU 最高温度达到 90°C 时，保护升速直接生效，不受平滑限制。

从 0.2.3 起，常规硬件采样和遥测刷新约每 2 秒一次，温度与传感器故障在下一次采样时处理。后台仍每秒检查失联超时和系统热状态，serious/critical 热状态、超时恢复与恢复失败重试均绕过读数缓存。隐藏、最小化或完全遮挡窗口会暂停遥测重绘，风扇控制和菜单栏读数继续运行。

“保存”保留预设，“应用”改变当前风扇控制。关闭窗口后应用继续留在菜单栏；退出时尝试恢复系统自动控制。“全部自动”可以随时交回系统管理。

预设与偏好保存于：

```text
~/Library/Application Support/FanDesk/presets.json
```

## 升级

1. 在旧版选择“全部自动”，确认两风扇已回到自动模式，然后退出应用。
2. 在系统登录项设置中关闭 FanDesk 后台运行，等待旧服务停止。
3. 将旧应用移动到备份位置，再复制新版到 `/Applications/FanDesk.app`。
4. 重新开启后台运行并打开新版。必要时点击“启用风扇控制”刷新服务注册；系统可能再次要求确认。

应用更新会改变代码签名，因此不要直接覆盖正在运行的版本。预设文件不在应用包内，替换应用不会删除预设。

## 卸载

先选择“全部自动”，关闭应用内的登录启动选项，然后退出。在系统登录项设置中关闭 FanDesk 后台运行，再将 `/Applications/FanDesk.app` 移到废纸篓。可以保留预设文件以供后续安装使用。
