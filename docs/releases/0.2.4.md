FanDesk 0.2.4 修复全速后切换预设的误提示、界面卡顿触发的控制中断，以及固定转速编辑区首次打开卡顿。

## 修复

- “全部全速”只改变正在运行的控制，保留预设编辑内容，不再凭空产生未保存修改。需要保存全速配置时，仍可点击“读取当前控制”后另存为预设。
- 心跳移至独立队列，界面布局和编辑操作不再阻塞心跳。保留 5 秒失联保护、睡眠及退出时的控制释放、高温保护和转速范围检查；真正失联时明确提示恢复系统控制的原因。
- 固定转速滑块改为连续调整，避免上千个刻度的重复布局，保留整数 RPM 和原有精确输入框。

## 验证

通过 **116 项核心检查 + 48 项应用模型/启动检查，共 164 项**。

在 Apple M5 Pro（Mac17,8）、macOS 27.0.1 上，已验证双风扇全速、全速后切回已保存预设、固定转速编辑区首次打开、拖动和精确输入；暂停整个应用后仍恢复系统自动控制。测试结束后恢复原温控预设，预设和偏好文件逐字节保持一致。实测来自相同程序代码的开发构建，分发构建另核对主程序与后台可执行代码段一致。

以上是本机短时结果。真实睡眠/唤醒、登录隐藏启动、其他机型和旧系统仍未完成全面验证，详见 [验证记录](https://github.com/sivdead/FanDesk/blob/v0.2.4/docs/validation.md)。

## 下载与升级

下载 **FanDesk-0.2.4-macos-arm64-notarized.dmg**。应用与 DMG 均使用 Developer ID 签名、通过 Apple 公证，并附带离线公证凭证。

首次安装将 FanDesk.app 拖入 Applications，再从“应用程序”打开，点击“启用风扇控制”并按 macOS 提示允许后台运行。

升级先选择“全部自动”并退出旧版，在系统登录项中关闭 FanDesk 后台运行；备份旧应用后复制新版，再重新开启后台运行。必要时点击“启用风扇控制”刷新注册并完成 macOS 认证，原有预设保留。详见 [安装指南](https://github.com/sivdead/FanDesk/blob/v0.2.4/docs/installation.md)。

将 DMG 与 **SHA256SUMS-notarized.txt** 放在同一目录，运行 `shasum -a 256 -c SHA256SUMS-notarized.txt` 检查下载完整性。历史版本及安装资产保留。
