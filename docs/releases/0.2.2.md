FanDesk 0.2.2 改善温控时转速频繁起落的问题，并包含关闭窗口后隐藏 Dock 图标的修复。

**2026-10-15：新增 Developer ID 正式签名与 Apple 公证安装包。** 应用与磁盘映像均已附带公证凭证，可供 macOS 离线验证。

## 变化

- 温控加入 4 秒时间常数的指数平滑，减少短时温度尖峰引起的转速变化。
- 正常目标转速每秒最多上升 300 RPM、下降 75 RPM；两个风扇分别维护状态，重复应用预设不会加快降速。
- 原始选中温度达到曲线上限、CPU 最高温度达到 90°C，或系统热状态为 serious/critical 时，手动控制的风扇仍立即全速。温控保护解除后缓慢降速；传感器失效或心跳超时仍交回系统控制。
- 从自动或固定转速切回温控时衔接当前转速；更换传感器和曲线时保留转速衔接。
- 关闭最后一个窗口后隐藏 Dock 图标，风扇控制继续在菜单栏运行；重新打开窗口时恢复 Dock 图标。
- 应用与 DMG 内包含 MIT 许可证，保留第三方声明。

升级保留已有预设和偏好，不会自动修改温度规则。本次实机验证使用双侧 CPU 平均温度 **40–75°C** 曲线；这不是所有机型的通用默认值。

## 下载与升级

推荐下载下方 **FanDesk-0.2.2-macos-arm64-notarized.dmg**。首次安装将 **FanDesk.app** 拖入 **Applications**，按 macOS 的正常来源确认提示打开，再点击“启用风扇控制”，按系统提示允许后台运行。

升级时先恢复“全部自动”并退出旧版，在系统登录项中关闭 FanDesk 后台运行；将旧应用移到备份位置，再复制新版。重新开启后台运行并打开新版，必要时点击“启用风扇控制”刷新注册并完成 macOS 认证。不要覆盖正在运行的应用文件。

带 `-notarized` 的安装包已使用 Developer ID 正式签名并通过 Apple 公证。原始 **FanDesk-0.2.2-macos-arm64.dmg** 及 **SHA256SUMS.txt** 保留，仍为未公证的本地签名版本。公证包的程序代码、应用版本和原 `v0.2.2` 源码标签保持一致，更新了分发签名、运行保护、时间戳、公证凭证和安装说明。详见 [安装指南](https://github.com/sivdead/FanDesk/blob/main/docs/installation.md)。

## 验证与兼容性

- **137 项自动检查通过**：104 项核心检查、33 项应用模型和启动检查，包括平滑、切换模式、缓慢降速和高温保护。
- 两种 DMG 均完成只读挂载、版本、arm64 架构、嵌套签名和许可证检查；原始包与本机已验证构建一致，公证包与已正式签名并附凭证的输入一致。
- 公证包的应用与磁盘映像均获 Apple Accepted，日志无问题；离线凭证、Gatekeeper 和应用 `syspolicy_check` 检查通过。
- 原始 0.2.2 构建已在本机安装并完成两分钟硬件读回：两侧控制持续生效，实际转速相邻约一秒采样的最大变化均为 62 RPM。高温保护通过模拟检查验证，未主动制造高温负载。
- 同一段真实温度序列回放中，仅增加平滑使目标转速累计变化量减少 69.8%；这是算法回放结果，不是声学或长期散热测试。
- 支持范围为 **Apple Silicon（arm64）、双风扇机型**；已实测 Apple M5 Pro（Mac17,8）、macOS 27.0.1，最低构建目标 macOS 14。
- 公证签名版本尚未替换本机应用；首次安装和后台授权运行验证仍待补充。其他机型和旧系统、真实睡眠/唤醒与登录隐藏启动也尚未完成验证。完整范围见 [验证记录](https://github.com/sivdead/FanDesk/blob/main/docs/validation.md)。

将公证 DMG 与 **SHA256SUMS-notarized.txt** 放在同一目录，运行 `shasum -a 256 -c SHA256SUMS-notarized.txt` 检查下载完整性。原始 DMG 对应的校验文件仍为 **SHA256SUMS.txt**。
