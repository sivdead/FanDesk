FanDesk 首个公开安装包，提供原生 macOS 双风扇控制和菜单栏温度监测。

## 下载与安装

下载下方 **FanDesk-0.2.0-macos-arm64.dmg**，打开后将 **FanDesk.app** 拖入 **Applications**。首次运行点击“启用风扇控制”，按 macOS 提示允许后台运行。

安装包采用 ad-hoc 本地签名，**没有 Developer ID 签名或 Apple 公证**。首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。请参阅 [安装指南](https://github.com/sivdead/FanDesk/blob/v0.2.0/docs/installation.md) 和 [Apple 官方说明](https://support.apple.com/102445)。

## 主要功能

- 两个风扇分别选择自动、固定 RPM 或独立传感器温控。
- CPU、GPU、电池、SSD 等温度监测，支持分类与搜索。
- 命名预设的保存、切换、重命名和删除。
- 菜单栏温度与 RPM 显示、单风扇控制和预设快捷操作。
- 登录启动、启动/唤醒恢复选项，以及退出和失联时恢复系统自动控制。
- 分发包不再绑定构建者 UID，仅允许当前活动控制台用户通过已校验签名的应用进行控制。

## 兼容性与已知限制

- **Apple Silicon（arm64）、双风扇机型**；已验证 Apple M5 Pro（Mac17,8）。
- 最低构建目标 macOS 14；实机验证系统为 macOS 27.0.1。
- Intel、无风扇和单风扇机型暂不支持，其他机型和旧系统尚未验证。
- 真实睡眠/唤醒、登录隐藏启动和跨机器首次安装仍待补充验证，详见 [验证记录](https://github.com/sivdead/FanDesk/blob/v0.2.0/docs/validation.md)。

## 校验

构建通过 111 项自动检查；DMG 挂载内容、嵌套签名及 arm64 架构已核验。

将 DMG 与 `SHA256SUMS.txt` 放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 检查下载完整性。升级现有版本前，请先恢复全部自动、退出并关闭旧后台服务，再替换应用。
