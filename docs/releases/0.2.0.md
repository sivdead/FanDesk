首个公开版本，提供原生 macOS 双风扇控制和菜单栏温度监测。

## 功能

- 两个风扇分别选择系统自动、固定转速或传感器温控。
- CPU、GPU、电池和 SSD 等温度监测，支持分类与搜索。
- 保存、切换、重命名和删除自定义预设。
- 菜单栏显示温度与 RPM，提供单风扇控制和预设快捷操作。
- 登录启动及启动、唤醒时恢复控制的选项；退出或失联时恢复系统自动控制。
- 源码和应用采用 MIT 许可证。

## 安装

面向 Apple Silicon 双风扇 Mac，最低系统要求为 macOS 14。已在 Apple M5 Pro（Mac17,8）验证，其他机型和旧系统尚未实测。

此历史版本未通过 Apple 公证，建议安装[最新版](https://github.com/sivdead/FanDesk/releases/latest)。安装与后台授权步骤见[安装指南](https://github.com/sivdead/FanDesk/blob/main/docs/installation.md)。
