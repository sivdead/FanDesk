# FanDesk 0.2.0 验收记录

验证日期：2026-10-13（Asia/Shanghai）。实机：Mac17,8 / Apple M5 Pro；系统：macOS 27.0.1。

## 自动检查

68 项核心检查和 33 项实际应用模型/启动检查通过，共 101 项。覆盖独立风扇模式、转速约束、温控曲线、传感器失效、心跳超时、恢复失败重试、旧预设迁移、持久化失败、异步旧回复、并发操作、睡眠/唤醒状态及登录启动事件判定。

检查入口为 `bash scripts/build.sh`。模拟的睡眠通知和登录事件仅证明对应代码路径，不代表实机睡眠或登录已验收。
